# 主页像素图标

当前主页已改成通过Kitty图片协议显示原始高清PNG；tui/src/home_art.rs直接include_bytes引用项目根目录原文件，未裁剪或降采样。下述64×64数据为先前像素字符方案的存档，目前不参与构建或显示。

`home-wolf.rgba`：64×64 RGBA原色像素数据，来自项目根目录用户提供的“复古终端像素狼头音乐图标.png”。按alpha>=32的可见区域去除外围透明留白，再用最近邻等比适配64×64透明画布。原文件保持不变。

通过include_bytes嵌入程序，主页用▀字符的前景/背景分别呈现上下两个像素；透明像素与当前主页板块背景混合，无运行时解码或Kitty图片依赖。
